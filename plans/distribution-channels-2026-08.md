# Distribution channels beyond SEO — 2026-08-22

Companion to `seo-plan-2026-08.md`. Constraints: solo founder, ~20 hrs/week GTM, PLG motion, no paid budget yet.

## Tier 1 — channels that are search engines themselves, where the asset already exists
1. **Platform marketplaces** — Zapier app directory, n8n community node + workflow-template gallery, Make app list, WordPress.org plugin directory, Shopify app store. Each ranks on its own domain for long-tail ("n8n screenshot node", "zapier pdf generator"). Webhook how-tos (our five integration pages) do not appear in these directories; a listed app/node does. Start with **n8n** (community node = small npm package; template gallery has real SEO), then Zapier (backend has a `zapier-integration` folder). 
2. **Public template gallery as pSEO** — the existing PRD (`PRD_PUBLIC_TEMPLATE_GALLERY_REMIX_SHARE.md`). Every public template becomes a landing page ("course completion certificate template", "podcast episode OG image") with a "Render this" CTA; inventory generated by the template agent, not hand-written. Canva/Bannerbear run on this.
3. **Powered-by loop on shared results** — `/r/` short links and share buttons exist. Add a "Made with Pictify — render yours" footer to guest-rendered share pages so every posted free-tool render refers. Zero content cost, compounding.

## Tier 2 — developer distribution (cheap, durable)
4. Package registries & API catalogs — npm/PyPI SDKs (publish if not already), Postman public workspace, RapidAPI listing.
5. Connector directories for non-developers — Anthropic connectors directory, a GPT-store GPT (MCP directories already done).
6. Dev.to / Hashnode cross-posts of AEO blog posts with canonical back to pictify.io (borrowed authority for "programmatic video", "puppeteer mcp").

## Tier 3 — already planned; execution only
